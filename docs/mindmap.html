lume-lan · 家庭局域网看板

lume-core(Lume DSL 服务端) + React + 宿主 Python 脚本 · 网关华为 WS5102(CAT 协议逆向)

架构 三层

  • 宿主层(Python3 纯标准库)
    • scan_lan.py → .data/devices.json(arp + 可选 sweep)
    • router_fetch.py → .data/router.json(登录+HostInfo/topology/wan)
    • daily_digest.py 24h 日报
    • webhook_notify.py 钉钉/企微
    • mac_block.py MAC 黑名单
  • Lume 服务端
    • lan.lume:server{} + 4 路由 + run()
    • devices.lume 只读领域层(无状态)
    • /api/devices · /api/meta · /api/router · /api/router-traffic
  • React 前端
    • esbuild → www/app.js(dev 热更, 仓库存压缩版)
    • 单页看板 + 筛选/点选交互

数据流 60s 循环

  • make dev 后台循环: scan + router-fetch 每 60s
  • .data/*.json 宿主/容器共享只读(volume)
  • 流量历史 每 IP 300 点 ≈ 5h + 全家庭总序列
  • 命名层 aliases.json(本地) > 路由器备注 > HostName > 厂商
  • 状态文件 alert_state / blocklist / digest_state

协议逆向 WS5102 CAT

  • 登录 简单 SHA256 路径(与网页 SCRAM 限流独立)
    • 限流冷却 5min + stale 数据沿用
  • 可用端点 200
    • HostInfo(32 台终端+流量) · topology(RSSI) · wan(状态/峰值)
    • wlanfilterenhance(MAC 准入) · getmacaddress · deviceinfo(免密)
  • 做不了的 404 qosclass_host / dms / access_auth → 无 QoS 限速 API

告警 & 通知 钉钉群

  • 🆕 新设备进网(MAC 基线, 首次静默)
  • 🌐 WAN 状态跳变
  • 📈 异常流量 ≥10GB/1h(30min 去重)
  • ⚠️ 关键设备离线(CRITICAL_IPS, 上线恢复报)
  • 📶 每日日报(在线数+流量 Top5+带宽峰值)
  • 命令 make notify-test / daily-digest / block|unblock|block-list

部署 本地 + 容器

  • 本地 make dev → :8091(esbuild watch + 数据循环)
  • Docker vendor/ 离线装静态 Lume + HEALTHCHECK → :10091
    • 容器只做 serve+读快照; arp 扫描必须宿主
  • 一键 make docker-redeploy(数据+前端+镜像+重启)

界面功能 看板

  • KPI(全网口径) + WAN 状态卡(连接/IPv4/DNS/NAT/峰值)
  • 流量趋势曲线(峰值时刻 + 主因设备)
  • 设备类型 / Wi-Fi 频段 点击筛选
  • 流量 Top5 → 点选: 设备详情卡 + 单设备 5h 曲线
  • 终端列表: 默认只看活跃; RSSI 信号柱; 备注名同步
  • CSV 导出 · 移动端响应式
